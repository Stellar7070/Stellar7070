### [Statement to Sheet](https://github.com/Stellar7070/statement-to-sheet)
Convert bank statements (CSV, OFX/QFX, or PDF) into Excel or CSV files. It runs locally, masks account details, and does not use external APIs. PDF conversion is best-effort.

### [AI Homeless Navigator — prototype](https://github.com/Stellar7070/ai-homeless-navigator3)
A React and Vite prototype with an AI assistant, resource finder, guides, and a saved-list/checklist dashboard.

> Prototype note: The resource listings are sample data, and ZIP/city search is currently cosmetic—not live resource data or location search.

### [Rookie Impact Tracker Data](https://github.com/Stellar7070/rookie-impact-tracker-data)
A public mirror of four nflverse-derived data files, with a scheduled script that pulls them into the live site.
